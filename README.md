golf.py

simple 2d grid-based golf game

comes with 10 levels + level summary screen on win
features green (grass), white (ball), red (flag), yellow (sand) and black (wall) tiles
built in relatively modular way, so extra functionality (tiles, levels, multiplayer) could be added fairly easily
requires python 3.14, no extra materials. uses pygame, random and time (libraries)
